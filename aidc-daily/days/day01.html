$ dmesg -T | grep -i xid
NVRM: Xid (PCI:0000:5a:00): 79, GPU has fallen off the bus.
↑ 冒号后面这个数字，就是 XID 码
立即隔离
重启恢复
盯住趋势
先查应用
显存 ECC
48
双比特 ECC（DBE）

显存数据已损坏。立即隔离，重启触发 Row Remap

95
未遏制的 ECC 错误

错误可能波及其他进程。隔离 GPU，重启节点

64
行重映射 / 页退役失败

备用行耗尽，无法自愈。直接换卡

94
已遏制的 ECC 错误

只有受影响的应用退出。重启应用即可

63
行重映射 / 页退役记录

自愈机制在工作。单次忽略，次数上升要警惕

92
单比特错误率过高

ECC 还能纠正，但显存在退化。排期更换

固件与连带
119
GSP RPC 超时

GPU 系统处理器无响应。重启节点，升级驱动

45
通道被预先清理

常是前序错误的连带结果。先找它前面的 XID

总线与互联
79
GPU 掉出 PCIe 总线

最典型的掉卡。冷重启，重插换槽仍复发 → RMA

74
NVLink 错误

nvidia-smi nvlink -e 查 CRC；持续增长查线缆 / NVSwitch

应用层（不是坏卡）
13
图形引擎异常

多为 CUDA 程序越界。查代码，别急着报修

31
显存页错误（MMU）

非法内存访问。排除代码后再跑诊断

43
GPU 停止处理

应用出错被驱动终止。重启应用即可

DBE 之后怎么判
nvidia-smi -q -d ROW_REMAPPER
Pending: Yes→重启节点完成重映射
Failure: Yes→换卡
重映射后 DBE 复发→换卡
