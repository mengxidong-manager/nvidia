显存压力测试和功耗脉冲测试

时长为 NVIDIA 官方在 Hopper 系统上的测量值；每一级都包含前一级的全部测试

什么时候跑哪一级
节点接活前→r1

快速就绪检查，放进调度前置脚本

作业刚失败→r2

等卡空闲后跑，先排除链路和显存

修好回生产→r3

drain 后跑，通过才 uncordon

送修 / 偶发故障→r4

隔离后跑，结果作为 RMA 证据

跑之前先确认

① nvidia-smi 里卡上没有作业进程
② r2 起节点已 cordon / drain，调度不会再派活

常用写法
dcgmi diag -r 3 -j

JSON 输出，方便进告警和工单

dcgmi diag -r memtest

只跑某一项测试

dcgmi diag -r "pcie,memory"

逗号分隔，跑多项

dcgmi diag -r 2 -i 0,1

只测指定的 GPU

dcgmi diag -r 3 --fail-early

压测途中发现失败就提前结束

dcgmi diag -r 2 --iterations 5

连跑多次，抓偶发故障

三条铁律

r3 / r4 会压满卡，
先 drain 再跑

按卡数留时间：
8 卡 r3 最长约 35 分钟

结果用 -j 存档，
留作 RMA 证据
