第一步：把日志打开
NCCL_DEBUG=INFO

生产常驻 WARN，排障临时开 INFO；TRACE 量太大，少用

NCCL_DEBUG_SUBSYS=INIT,NET

默认只有 INIT,BOOTSTRAP,ENV；查网络加 NET，查拓扑加 GRAPH

NCCL_DEBUG_FILE=/tmp/nccl.%h.%p.log

%h 主机名、%p 进程号，每个 rank 一个文件；不设就打到 stdout，和训练日志混在一起

日志里先找这三行
NCCL INFO Using network IB

IB = 走了 RDMA（IB 或 RoCE）；看到 Socket 就是退回了 TCP，带宽会掉一个量级

Channel 00/0 : 0[0] -> 8[0] [send] via NET/IB/0/GDRDMA

带 /GDRDMA = GPUDirect RDMA 生效；没有就要绕 CPU 内存

Channel 00/0 : 0[0] -> 1[1] via P2P/CUMEM

机内 GPU 直通（NVLink / PCIe）；变成 via SHM 说明机内没直连上

选网卡、配 RoCE
NCCL_IB_HCA==mlx5_0,mlx5_1

开头的 = 表示精确匹配，不加时 mlx5_1 会连 mlx5_10~19 一起选

NCCL_SOCKET_IFNAME=bond0

只管建连和 Socket 传输用哪个 IP 网口，不能把流量切到 IB

NCCL_IB_GID_INDEX

RoCE 用哪个 GID，默认 -1 自动选；不对时用 show_gids 查

NCCL_IB_TC

流量类别，默认 0；要和交换机的无损队列对上

双平面先数网卡：INFO 日志里 NET/IB 会列出用到的网卡，少一张就少一条 rail

只在排障时用
NCCL_IB_DISABLE=1

强制走 Socket，对比判断是不是 RDMA 层的问题

NCCL_P2P_DISABLE=1

关掉机内 GPU 直通，排查 NVLink / PCIe

NCCL_NET_GDR_LEVEL=LOC

关掉 GPUDirect RDMA，看是不是 GDR 引起

NCCL_ALGO / NCCL_PROTO

锁死算法和协议，怀疑 NCCL 选错时用

官方原则：这些变量会挡住 NCCL 自动选最优，问题解决就删掉，别留在生产脚本里

卡住不报错？先算超时
NCCL_IB_TIMEOUT=20每次等 4.096µs × 220 ≈ 4.3 秒
NCCL_IB_RETRY_CNT=7重试 7 次，网络断了约 30 秒才报错
TORCH_NCCL_ASYNC_ERROR_HANDLINGPyTorch 侧的出错处理，默认 3；旧名去掉 TORCH_ 前缀，已弃用
