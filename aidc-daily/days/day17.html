时间片怎么配
version: v1
sharing:
  timeSlicing:
    resources:
    - name: nvidia.com/gpu
      replicas: 4

写进 ConfigMap 还不够，要在 ClusterPolicy 的 devicePlugin.config.name 里引用才生效

申请 2 份 ≠ 2 倍算力；failRequestsGreaterThanOne 可直接拒绝

MIG 怎么切
kubectl label node <node> \
  nvidia.com/mig.config=all-1g.10gb \
  --overwrite

MIG Manager 看到标签就切，结果写在 nvidia.com/mig.config.state，success 才算完

切之前先把节点上的 GPU 任务排空；all-1g.10gb 适用 H100 / A100 80GB

single 策略整卡切成同一规格，资源仍叫 nvidia.com/gpu；mixed 才按规格分资源名

apiVersion: resource.k8s.io/v1
kind: ResourceClaimTemplate
spec:
  spec:
    devices:
      requests:
      - name: gpu
        exactly:
          deviceClassName: gpu.nvidia.com

K8s 1.34 起 GA，API 是 resource.k8s.io/v1，请求写在 exactly 下
