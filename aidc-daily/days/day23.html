机柜电容

毫秒级

GB300 电源架内置电解电容（每 GPU 65 J），训练时电网侧峰值最多降 30%

只平滑负载，停电时不供电

UPS / HVDC 电池

0 ms → 分钟

在线式 UPS、HVDC 的电池本来就挂在直流母线上，市电掉了直接放电

电池时间要盖住柴发起机和带载

机柜 BBU

0 ms → 4 min

锂电放进机柜，48V 直挂母线；不用集中 UPS 的机房常用

ORv3 每模块 3 kW、撑 4 分钟

看 BBU 健康度、循环次数

柴油发电机

≤10 s → 小时

NFPA 110 Type 10：10 秒内恢复供电；Uptime 各级都要求现场储油 ≥12 h

储油之外，要有补油合同

三个常见误解
✗ ATS 毫秒级无缝切换

切柴发要等起机，中间靠电池顶；
毫秒级切换的是 STS（静态转换开关）

✗ 机柜电容能扛停电

GB300 的电容只削峰填谷，NVIDIA 明确它只优化电网看到的负载

✗ 储油标准是 72 / 168 h

Uptime 最低要求 12 h（按 N 负载）；72 h 等是设计选择，不是标准

三条铁律

电池时间 >
柴发起机 + 带载时间

柴发定期带载演练，
不能只空载试机

电池定期测内阻、
做放电测试
