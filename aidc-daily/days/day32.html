要改的只有两个字段
主板 SNBoard Serialfield b 2
整机 SNProduct Serialfield p 4

区域代码：c 机箱 · b 主板 · p 产品
索引按 IPMI FRU 规范的字段顺序，从 0 开始

索引对照
Board 区 b
  1. Manufacturer
  2. Product Name
  3. Serial ← 主板 SN
  4. Part Number
  5. FRU File ID
Product 区 p
  1. Manufacturer
  2. Name
  3. Part Number
  4. Version
  5. Serial ← 整机 SN
  6. Asset Tag
  7. FRU File ID

2先备份fru read 0 before.binfru print 0 > before.txt

两份都拷到本机之外

新旧 SN 位数一致再动手

5BMC 冷复位mc reset cold

6交叉验证dmidecode -s system-serial-number

主机重启后 SMBIOS 才更新

看到这些立刻停
fru print 报 checksum 错FRU 已损坏，找厂商
目标 SN 对不上工单不凭猜测写入
写入过程中不断电、不重启 BMC
新旧长度不一致ipmitool 会重排整个 FRU，风险高
写错了怎么回滚
fru write 0 before.bin mc reset cold

回滚后再 fru print 0，两个字段逐字符核对。
没有 before.bin 就没有回滚。
