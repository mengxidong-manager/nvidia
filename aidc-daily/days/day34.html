RAID 020数据全丢，只能靠备份
RAID 121降级运行，换盘自动重建

RAID 不是备份。动手前先确认最近一次备份可用。

热插拔换盘六步（perccli）
1确认降级perccli /c0/v0 show

State: Degraded，系统还在跑

2找到坏盘perccli /c0/eall/sall show

记下 Enclosure:Slot 和序列号

3点灯再拔perccli /c0/e32/s2 start locate

灯对上了再拔，别碰相邻盘

4插新盘

同型号，容量 ≥ 原盘
等 10～30 秒被识别

5盯重建perccli /c0/eall/sall show rebuild

没自动开始：set good → start rebuild

6收尾perccli /c0/v0 start cc

Optimal 后跑一致性检查，记日志

三种最危险的时刻
RAID 0 坏盘数据重要又没备份：别重建、别拔盘，找数据恢复
RAID 5 重建中所有盘满负荷，再坏一块就全丢；大盘建议 RAID 6/10
RAID 10 同组双坏该镜像组数据没了，整个阵列失败
配一块热备盘
perccli /c0/e32/s7 add hotsparedrive perccli /c0/e32/s7 add hotsparedrive DGs=0

第一条：全局热备，任何阵列都能用
第二条：只给磁盘组 0 用
坏盘后秒级开始重建，不用等人到场
